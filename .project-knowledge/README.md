## Fast Facts

- **Stack**: Node.js + Express 5 + Mongoose 9 + MongoDB. CommonJS.
- **Entry points**: `server.js` (env load → fail-fast DB connect w/ retries → listen), `app.js` (middleware + route mounting).
- **Base URL**: `/api/v1`; health check at `GET /`.
- **Auth**: JWT access token (Bearer header or httpOnly `jwt` cookie) + rotating refresh token (httpOnly `jwt_refresh`); account activation required; Google OAuth (ID-token) signup/login.
- **RBAC**: `authorize(resource, action)` enforced on all mutating resource routes via the 12-permission matrix seeded by `npm run seed`.
- **Soft deletes**: `deletedAt` pattern on all core entities; AuditLog & StockMovement are immutable.
- **Redis**: cache + rate limiting, fails open to MongoDB/in-memory when unavailable.
- **Biggest known issues**: `?search=` `$text` only works on Products; purchase receive is not transactional; purchase cancel doesn't reverse stock; Brevo email failures now re-throw (500).
